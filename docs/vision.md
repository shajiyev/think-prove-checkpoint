# Vision

## What we're building
A ~30-page PDF guide, **"Think · Prove · Checkpoint"**, that is also the installer: hand it
to your own AI agent (Claude Code, Codex, …) and it sets the workflow up with you in
conversation, tailored to you. A public GitHub repo holds the same files plus scripts and
tests, for technical readers.

## Why
Most people use Claude Code in a way where it forgets everything between sessions,
guesses silently, says "done" without proof, and keeps memory in places you can't review.
This workflow fixes that with three layers: principles (Karpathy), process (superpowers
skills) and memory (plain docs in git). The guide shares it, and shows how I work.

## Users
- Solo developers who know the basics of Claude Code (or another agent) and want a repeatable workflow.
- LinkedIn readers (recruiters, peers): it shows project management with a technical
  emphasis, backed by this repo's own roadmap, decisions, specs and plans.

## Goals
- A reader can understand the whole system from the PDF alone.
- A reader can install it from the PDF alone, by chatting with their agent, tailor it, and
  fully revert it later, even in a new session.
- No manual steps needed; the repo is optional.
- The repo itself is evidence: built with the workflow, history visible.

## Non-goals
- Not a Claude Code beginner tutorial (we assume it's installed and they've used it).
- Not a LinkedIn carousel (a teaser may come later, separately).
- No copying of the original solo-dev guide's text, layout details or branding.
- No invented anecdotes or results.
